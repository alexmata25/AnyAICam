Customer setup flow

Step 1

Connect the Edge appliance

Connect power and Ethernet to the same network that can reach the cameras. The appliance checks in securely to AnyAiCam.

Step 2

Sign in / activate

Use the customer account created from the paid order. The backend links the appliance to the correct customer, site and purchased entitlements.

Step 3

Discover cameras

The Edge appliance scans the authorized local network for supported cameras. Discovery occurs locally, not from the public website.

Step 4

Enter camera credentials

The customer supplies credentials they are authorized to use. Credentials stay in the secure appliance/VMS credential path and are not sent through the website checkout.

Step 5

Assign camera slots

Select a discovered camera, give it a useful name and assign it to one of the camera slots purchased with the system.

Step 6

Commission and finish

AnyAiCam verifies camera connectivity, live view, recording and the licensed feature set before declaring the site ready.

What the purchase already prepared

By the time the appliance arrives, the system should already know what that customer is allowed to activate.

Customer & site

Identity, site name and order association.

Camera capacity

The purchased number of camera slots so discovery cannot over-assign the system.

Feature rights

Analytics, cloud retention and other licensed modules attached to the correct slots/site.

Appliance assignment

The shipped device is associated with the paid order and activation record.

Cloud association

The backend has the customer/site namespace and service configuration needed for permitted cloud features.

Commissioning policy

Required checks that must pass before the customer sees “System Ready.”

Which hardware path applies?

The appliance depends on what the customer actually purchased

Standard VMS

MINISFORUM AI X1-255 — Ryzen 7 255 is the normal starting point. MINISFORUM AI X1 — Ryzen AI 9 HX 470 is used when the validated workload needs more headroom.

Integrated AAC Face Access

Use the AI Access Edge when Face Access is connected to a supported access-control provider API.

Standalone access control

The Numato relay is a separate local door/gate-control path. It is not a required accessory for either VMS Edge appliance or the AI Access Edge.

Optional premium setup

If AAC Face Access was purchased

After the cameras are commissioned on an AI Access Edge, an administrator can connect a supported access-control provider API, link an entrance camera to a door and enroll authorized people. Standalone relay access follows a separate local commissioning path.

01

Connect provider

Enter the access-control API credential in the protected admin setup, not at website checkout.

02

Link camera + door

Map the entrance camera to the correct access-controlled door.

03

Enroll faces

Create consented resident/employee face templates and access schedules.

04

Test policy

Verify recognition, liveness, access rules and the provider unlock response.

05

Go live

Door unlock actions are permission-controlled and logged for audit.

What the website should never ask the customer to do

No AWS setup

The customer should never create S3 buckets, IAM users or cloud credentials. Provisioning is server-to-server.

No VMS code edits

New customer #100 should activate through the same standardized flow as customer #1.

No camera passwords at checkout

Camera credentials are entered only during the secure local/edge setup after the device is on the customer's network.
