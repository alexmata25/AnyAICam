Simple deployment

Ship the Edge. Plug it in. Discover the cameras. Start using the VMS.

AnyAiCam is built for existing camera systems. The goal is to avoid replacing cameras that already work: connect an AnyAiCam appliance to the customer network, discover compatible cameras, assign purchased slots and enable the features they bought.

Local-first

Your cameras keep recording at the site.

Local VMS recording and playback run on the AnyAiCam appliance. A camera license is not tied to a camera's IP address or device, so a failed camera can be replaced without purchasing the same license again.

  • Existing compatible cameras
  • Local storage
  • AnyAiCam Starter or Professional appliance, or your own Ubuntu 24.04 PC
  • Optional analytics per selected slot
Hybrid

Add cloud-connected event services without making cloud video the default path.

Hybrid keeps local recording while adding cloud metadata, event thumbnails, notifications and remote services where configured. Direct/P2P media is preferred when available; relay is a fallback path.

  • Local recording remains primary
  • Cloud event services
  • Optional analytics
  • Remote access services

AAC Face Access

Access control stays a separate product path.

Face Access

AnyAiCam Enterprise appliance performs local face matching and requests the door unlock. Access-control platform integrations are coming soon. API credentials belong in protected setup—not in public website code.

Numato relay door control

The Numato 3-channel Ethernet relay drives the strike/maglock/access-power-supply electronics for AAC Face Access and can also be used on its own. Access-control platform integrations are coming soon.
