AnyAiCam Edge

The always-on local center of your VMS.

The AnyAiCam appliance sits on the same customer network as the cameras. It is the component that can discover local cameras, maintain camera connections, record locally and run the site-level VMS services.

Edge responsibilities

  • Live/recording pipeline
  • Local VMS services
  • Secure cloud registration
  • Entitlement enforcement

Why use an AnyAiCam appliance?

Local network access

A public cloud website cannot safely scan a customer's private camera network. The AnyAiCam appliance can perform discovery from inside the site.

Local recording

Core video recording can continue locally even when optional internet/cloud services are temporarily unavailable, subject to the configured system design.

Simpler customer setup

The customer receives a prepared device, connects it to the network, activates it and completes camera discovery instead of building a VMS server from scratch.

Customer installation target

Physical steps

  1. Connect the AnyAiCam appliance to power.
  2. Connect Ethernet to the camera/site network.
  3. Confirm the appliance is online.
  4. Open the AnyAiCam account or activation page.

Software steps

  1. Sign in and claim/activate the appliance.
  2. Run Discover Cameras.
  3. Select each authorized camera and enter its credentials.
  4. Assign cameras to purchased slots and names.
  5. Run commissioning and finish.
Higher-performance option

AnyAiCam Enterprise appliance for AAC Facial Recognition

Sites that purchase AAC Face Access would use a higher-performance Edge tier sized for local face detection, face-template matching and access-policy decisions (liveness checks coming soon) in addition to the normal VMS workload.

Local face processing

Keep recognition close to the cameras for lower latency and better privacy control instead of sending every face frame to a public website.

Access-control API adapter

Connect the site to a supported access-control provider that exposes a documented API. Provider credentials belong in a protected server/edge secret store, never in public page JavaScript.

Door-linked cameras

Associate an entrance camera with a specific door. Authorized users can see a door-unlock icon on that camera card, while recognized enrolled users can unlock through the same policy engine.
