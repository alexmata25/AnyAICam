Starter Camera Trial Path

Don’t Know Your Camera Password? You Can Still Try the Cloud.

Many existing camera systems are locked behind an unknown administrator username or password. Instead of paying for a technician before you have seen the platform, start with one compatible evaluation camera, the free Windows Software Bridge and a 30-day cloud trial.

See How It Works I Know My Camera Login

The Goal

Experience the VMS before changing your whole system.

The starter camera is a simple evaluation tool. It lets you see live video, playback, remote access and alerts in a real installation. It is not presented as the long-term replacement for every camera.

How the Starter Path Works

One camera. One free software bridge. One real-world cloud trial.

This path is designed for customers who want to experience the platform now but cannot access their existing cameras yet.

1

Order one starter camera

Use one compatible camera to evaluate the platform without resetting your entire existing system first.

2

Install the free software

Run the Windows Software Bridge on a compatible computer that stays powered on and connected.

3

Activate the 30-day trial

See live view, cloud playback, remote access and supported alerts using a real camera at your location.

4

Choose your long-term path

Reset and add your existing cameras, upgrade to professional cameras, or keep using only what fits your needs.

Path A

You know your camera login

Use your existing compatible camera or NVR and start with the free Windows Software Bridge. No starter camera is necessary.

Start Free Software Trial

Path B

You do not know your camera login

Start with one compatible evaluation camera so you can experience the VMS before hiring a technician or replacing your existing camera system.

Request Starter Camera Details

What Happens After the Trial?

You decide what to do next.

The starter path is meant to help you understand the platform—not pressure you into replacing every camera.

Add your existing cameras

Recover or reset the camera credentials, then add cloud subscriptions for the cameras you want to keep.

Upgrade selected locations

Replace only the cameras that need better image quality, reliability or professional features.

Stop after the trial

Cloud billing does not need to continue if the platform is not the right fit. Any camera purchase remains a hardware purchase.

Ready to Try It?

Choose the path that matches your camera access.
