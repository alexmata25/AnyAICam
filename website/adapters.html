Videoloft Cloud Adapter Options

Choose the right hardware to bridge your existing NVR or camera system to the Videoloft cloud. Adapter hardware ordered through ANY AI CAM. Cloud recording billing handled by Videoloft directly.

Customer Choice

Choose the activation path that fits your site.

The Videoloft Cloud Adapter hardware is handled exclusively by ANY AI CAM. Cloud recording is configured during your request and billed directly by Videoloft after activation.

1

Videoloft Cloud Adapter Path

The adapter path is for customers who prefer dedicated, always-on hardware without relying on a running computer. Orders include both adapter hardware and cloud setup in one request.

  • Ideal for Mac users or environments without a dedicated Windows PC
  • Ensures cloud recording continues even if a computer shuts down
  • Perfect for setups requiring network bridge hardware (e.g., legacy NVRs, hybrid systems)
  • Adapter selection based on your camera count and network layout
  • Hardware purchased through ANY AI CAM; cloud billing begins after 30-day trial
  • Final setup instructions sent after billing confirmation
2

Software / Cloud Direct Path

For customers who already have a compatible NVR or PC that can run the cloud bridge software. No additional hardware purchase needed.

  • Ideal for existing Windows-based NVR systems
  • No hardware adapter required - uses your existing computer
  • Camera connects directly to cloud via software bridge
  • May require a dedicated PC or server running 24/7
  • Recommended for IT-proficient users
