AnyAiCam for Linux

Install AnyAiCam on your own Ubuntu 24.04 PC.

AnyAiCam 1.2.2 runs on a PC with Ubuntu 24.04 LTS (64-bit Intel or AMD). Prefer a ready-made system? An AnyAiCam Ryzen appliance arrives with AnyAiCam installed and a licence included.

Before you start

Computer

  • Ubuntu 24.04 LTS, 64-bit (a fresh install is recommended)
  • 64-bit Intel or AMD processor with 4 or more cores
  • 8 GB RAM or more; 16 GB recommended
  • 100 GB free storage, plus storage for recordings

Network

  • Wired connection on the same network as your cameras
  • Internet access during installation
  • Ports TCP 8000 and UDP 8189 free on this PC

Account

  • An AnyAiCam account with a VMS licence
  • A licence comes with every AnyAiCam appliance, or add one for your own PC in My subscription
  • A Ubuntu user that can run sudo

Install

  1. Sign in to the AnyAiCam portal, open My subscription and select Download installer.
  2. Check the download is complete. In a terminal, in the folder you saved it to, run the first command below. The result must be 667ac892c123e640e7a93b62bc6792dc75b20b765c2401bc9b72821c2033efbb.
  3. Unpack it, run the installer, then run the built-in check:
sha256sum anyaicam-appliance-installer-1.2.2-vms-7ed690c84e73.tar.gz
mkdir -p ~/anyaicam-installer
tar -xzf anyaicam-appliance-installer-1.2.2-vms-7ed690c84e73.tar.gz -C ~/anyaicam-installer
cd ~/anyaicam-installer
sudo ./install.sh
sudo ./validate.sh
  1. In the AnyAiCam portal, follow Set up your appliance to link this PC to your account and add your cameras.

After installation

Updates

New versions appear in Settings → System. The account owner starts each install. Every update is checked before it installs, and if a new version does not start correctly the PC goes back to the version it was running.

Repair

Run sudo ./install.sh --repair from the installer folder. Recordings, cameras, settings and accounts are kept.
