# AnyAiCam v0.9.1 Release Notes

Release date: 2026-08-06

## Summary

Version 0.9.1 is a focused authentication reliability and security-maintenance release. It resolves the production login failure caused by incorrect same-origin URL classification in the shared browser fetch wrapper.

## Resolution

The wrapper now resolves request targets with the browser `URL` API and compares the resolved origin with `window.location.origin`. Relative paths, path-relative values, and absolute URLs on the current origin therefore receive `X-CSRF-Token`, while cross-origin requests do not.

Surrounding quotes are still removed from the decoded CSRF cookie value before the header is set. Redirect handling for successful authentication is unchanged. The server-side CSRF middleware was not weakened or bypassed.

## Verification

- Production login completed successfully and the administrator portal loaded.
- `/login`, `login`, and `https://app.anyaicam.com/login` attach the normalized CSRF header.
- An absolute cross-origin URL does not receive the header.
- The strict middleware continues to require a cookie, matching header, and valid signature.
- Temporary diagnostic logging was removed after confirming the first failing condition.

## Upgrade notes

No database migration, customer-data change, Docker-networking change, Cloudflare change, or AWS infrastructure change is required. Rebuild and recreate the VMS application container using the existing deployment procedure.
