## 1. Establish an isolated target and inspect it read-only

After the owner approves an isolated acceptance environment and the laptop is available, independently prove that the effective test process cannot access customer or production databases, credentials or writable host locations and cannot reach external networks. Before any application import, bind every test connection to that disposable target and verify the target independently. **Do not import `partner_db` or start the VMS for read-only inspection:** `partner_db` initializes its database and calls `apply_migrations()`. Use an existing read-only connection to the isolated database and call `gateway_schema_readiness.inspect_gateway_schema(db, 'postgresql')` through a connection adapter with the project's `?` placeholder and dictionary-row conventions; the helper does not connect or apply migrations. It reports missing/incompatible columns and index definitions, migration markers/order and duplicate current claims. Its PostgreSQL metadata handling has only synthetic coverage. An empty newly created database will be reported not ready; that is expected before approved initialization, not permission to migrate.

On an existing synthetic schema, record the results of these read-only conflict queries before requesting migration approval:

```sql
SELECT lower(device_id) AS device_key, count(*) AS n
FROM appliance_claims WHERE status IN ('pending','claimed') AND revoked_at IS NULL
GROUP BY lower(device_id) HAVING count(*) > 1;

SELECT appliance_id, count(*) AS n FROM appliance_claims
WHERE appliance_id IS NOT NULL AND status='completed' AND revoked_at IS NULL
GROUP BY appliance_id HAVING count(*) > 1;

SELECT appliance_id, count(*) AS n FROM internal_gateway_provisioning_authorizations
WHERE status='active' GROUP BY appliance_id HAVING count(*) > 1;

SELECT appliance_id, count(*) AS n FROM appliance_edition_provisioning_decisions
WHERE revoked_at IS NULL GROUP BY appliance_id HAVING count(*) > 1;

SELECT camera_id, count(*) AS n FROM cloud_gateway_camera_entitlements
WHERE status IN ('pending','active','suspended') GROUP BY camera_id HAVING count(*) > 1;
```

Run a query only if its table and required columns exist; otherwise record the schema as missing. Inspect row identities, status, expiry and ownership in an authorized synthetic dataset. Existing duplicates prevent unique-index creation. Do not delete, revoke, backfill or choose a winner automatically; stop for an owner-approved resolution. The readiness checker flags duplicates regardless of whether a session appears time-expired, because the partial index cannot use current time.
